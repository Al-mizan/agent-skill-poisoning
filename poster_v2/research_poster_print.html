  • Registry Scanner Blindness: Marketplace keyword regex filters miss non-English attacks, yielding 100% Vetting Bypass Rate (VBR).
Semantic Asymmetry

Keyword rules block English attacks but fail on cross-lingual equivalents, enabling silent tool exploit execution.

6. Security Impact

  • Supply-Chain Vulnerability: Third-party manifests execute as arbitrary tools. Attackers exploit multilingual blind spots with 100% VBR.
  • Self-Policing Failure: Reasoning LLMs cannot reliably arbitrate tool calls; prompt guards introduce 15.4%–23.1% utility loss.
  • Deterministic Seam Paradigm: Mediating calls at the in-process seam eliminates exploits (0% ASR in BN / BN-EN) with 0.037 ms overhead.
Strategic Security Directive

Do not rely on probabilistic LLMs for safety. Enforce deterministic, language-invariant authorization at the tool seam.

Deployment Recommendation

Integrate in-process authorization seams into agent frameworks (LangChain, AutoGen, CrewAI, MCP hosts) prior to mounting community skills.

7. Conclusion

  • Universal Cross-Lingual Risk: LLMs process low-resource and code-mixed manifests without safety triggers, achieving 100% exploit execution and 100% VBR.
  • Deterministic Defense Proof: In-process authorization cuts non-English ASR to 0.0% while preserving 100% benign utility (0.0% FDR).
  • Production Feasibility: 0.037 ms latency enables instant drop-in deployment without model retraining.
